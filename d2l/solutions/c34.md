        A: $
\frac{\partial^2 l}{\partial z_i \partial z_j} =
\begin{cases}
\hat{y}_i (1 - \hat{y}_i), & \text{if } i = j \\
-\hat{y}_i \hat{y}_j, & \text{if } i \neq j
\end{cases}
$

    2. 计算$\mathrm{softmax}(\mathbf{o})$
给出的分布方差，并与上面计算的二阶导数匹配。

        A: softmax 输出 \mathbf{p} 可以看作一个概率分布。我们可以计算这个分布的方差，以衡量 softmax 输出的分散程度。

        softmax 分布 $\mathbf{p}$ 的方差定义为：

        $\mathrm{Var}(\mathbf{p}) = \mathbb{E}[p_i^2] - (\mathbb{E}[p_i])^2$.

        其中，

        $\mathbb{E}[p_i] = \frac{1}{n} \sum_{i=1}^n p_i = \frac{1}{n}$,

        而

        $\mathbb{E}[p_i^2] = \frac{1}{n} \sum_{i=1}^n p_i^2$.

2. 假设我们有三个类发生的概率相等，即概率向量是$(\frac{1}{3}, \frac{1}{3}, \frac{1}{3})$

- 如果我们尝试为它设计二进制代码，有什么问题？

    Q: 	
    1.	二进制码长度的限制：二进制编码要求每个类分配一个唯一的二进制码，而通常编码的长度为整数位数。然而，由于有三个类，编码理论上应该为每个类分配 $\log_2 3 \approx$ 1.585 比特的平均码长。然而，二进制系统不能表示非整数的比特长度，这意味着我们无法为三个类设计出满足平均码长为 $\log_2 3$ 的编码。
	2.	码长的最小化：为了满足唯一性，最简单的二进制编码就是为每个类分配至少 2 比特长的编码（例如，类 1 用 00，类 2 用 01，类 3 用 10）。但这样设计的编码会导致平均码长为 2 比特，这比信息理论要求的最优码长 $\log_2 3 \approx$ 1.585 更长。这样就增加了编码的冗余性，即编码效率降低。
	3.	编码不平衡：因为每个类的概率是相等的，如果使用不等长的码来表示这三个类，也会带来编码的不均衡问题，难以保证平均码长的优化。因此，最优的编码要求每个类的编码尽可能短，但无法用二进制整位实现最优的 1.585 比特码长。


        总之，尝试设计二进制编码时会遇到的问题在于，三种等概率事件的平均码长不是整数，因此无法用固定长度的二进制码精确表示，同时也无法设计出符合信息论最优码长要求的编码。这导致编码效率较低，无法达到理论上的最佳压缩效果。

    A： 1. 联合编码的思路

假设我们有三个类别，记作 A、B 和 C。每个类别的发生概率都是 \frac{1}{3}，如果我们考虑两个独立观测结果的组合，就有 3 \times 3 = 9 种可能的组合：


(A, A), (A, B), (A, C), (B, A), (B, B), (B, C), (C, A), (C, B), (C, C)


因为每个组合的概率是相等的，即 \frac{1}{3} \times \frac{1}{3} = \frac{1}{9}，我们可以为这 9 种组合分配二进制编码。

2. 为组合分配二进制编码

    既然有 9 种组合，我们可以使用长度为 4 比特的二进制编码来表示。具体分配方式可以如下：

    | 组合       | 值       |
    | -------------- | -------------- |
    | (A, A) | 000 |
    | (A, B) | 001 |
    | (A, C) | 010 |
    | (B, A) | 011 |
    | (B, B) | 100 |
    | (B, C) | 101 |
    | (C, A) | 110 |
    | (C, B) | 111 |
    | (C, C) | 1000 |

    注意：这里为了更简洁，假设某些组合的编码长度为 3 比特即可表示。

3. softmax是对上面介绍的映射的误称（虽然深度学习领域中很多人都使用这个名字）。真正的softmax被定义为 $\mathrm{RealSoftMax}(a, b) = \log (\exp(a) + \exp(b))$

    1. 证明$\mathrm{RealSoftMax}(a, b) > \mathrm{max}(a, b)$

        A: 
        
        Case 1: a $\geq$ b

        Here, $\max(a, b) = a$. From the analysis above:

        $\mathrm{RealSoftMax}(a, b) = a + \log(1 + e^{b-a})$.

        Since $b-a \leq 0$, we know $e^{b-a} \leq 1$. Therefore:

        $\log(1 + e^{b-a}) > 0$.

        Thus:

        $\mathrm{RealSoftMax}(a, b) = a + \log(1 + e^{b-a}) > a = \max(a, b)$.


        Case 2: b > a

        Here, $\max(a, b) = b$. Similarly:

        $\mathrm{RealSoftMax}(a, b) = b + \log(1 + e^{a-b})$.

        Since a-b < 0, we know $e^{a-b} < 1$. Therefore:

        $\log(1 + e^{a-b}) > 0$.

        Thus:

        $\mathrm{RealSoftMax}(a, b) = b + \log(1 + e^{a-b}) > b = \max(a, b)$.

    2. 证明$\lambda^{-1} \mathrm{RealSoftMax}(\lambda a, \lambda b) > \mathrm{max}(a, b)$成立，前提是 $\lambda > 0$。

        A: 我们按照以下步骤来证明：

        1. 展开左侧表达式

            定义  $A = \exp(\lambda a)$  和  $B = \exp(\lambda b)$ ，根据定义，我们有：


            $\mathrm{RealSoftMax}(\lambda a, \lambda b) = \log(A + B).$


            因此，左侧表达式为：


            $\lambda^{-1} \mathrm{RealSoftMax}(\lambda a, \lambda b) = \frac{1}{\lambda} \log(A + B) = \frac{1}{\lambda} \log(\exp(\lambda a) + \exp(\lambda b)).$


        2. 观察右侧表达式

            设  $M = \max(a, b)$ ，假设  $a \geq b$ ，则  M = a 。我们要证明：


            $\frac{1}{\lambda} \log(\exp(\lambda a) + \exp(\lambda b)) > a.$


        3. 不等式变形

            将  $\frac{1}{\lambda} \log(\exp(\lambda a) + \exp(\lambda b)) > a$  转化为：


            $\log(\exp(\lambda a) + \exp(\lambda b)) > \lambda a.$


            因为  $\log(x)$  是单调递增的，我们可以将其化简为：


            $\exp(\lambda a) + \exp(\lambda b) > \exp(\lambda a).$


            这是显然成立的，因为  $\exp(\lambda b) > 0  （ \exp(x)  始终为正）。$

    3.  证明对于$\lambda \to \infty$，有$\lambda^{-1} \mathrm{RealSoftMax}(\lambda a, \lambda b) \to \mathrm{max}(a, b)$

        代入定义，我们有：


        $\mathrm{RealSoftMax}(\lambda a, \lambda b) = \log \left( \exp(\lambda a) + \exp(\lambda b) \right).$


        然后我们将其缩放为 $\lambda^{-1}$ 的形式：


        $\lambda^{-1} \mathrm{RealSoftMax}(\lambda a, \lambda b) = \lambda^{-1} \log \left( \exp(\lambda a) + \exp(\lambda b) \right).$


        使用主导项近似

        注意到当 $\lambda \to \infty$ 时，$\exp(\lambda a)$ 和 $\exp(\lambda b)$ 中较大的指数项将主导整个和。假设 a \geq b，则 $\exp(\lambda a)$ 是主导项，因此有：


        $\exp(\lambda a) + \exp(\lambda b) \approx \exp(\lambda a) \left( 1 + \exp(\lambda (b-a)) \right).$


        这里的 $\exp(\lambda (b-a))$ 会随着 $\lambda \to \infty$ 趋于 0（因为 b - a < 0），因此进一步得到：


        $ \exp(\lambda a) + \exp(\lambda b) \sim \exp(\lambda a).$


        计算对数项

        将近似结果代入对数表达式：

        $\log \left( \exp(\lambda a) + \exp(\lambda b) \right) \sim \log(\exp(\lambda a)) = \lambda a$.


        因此：$\lambda^{-1} \log \left( \exp(\lambda a) + \exp(\lambda b) \right) \sim \lambda^{-1} (\lambda a) = a$.


        类似地，如果 $b \geq a$，通过对称分析可得：


        $\lambda^{-1} \mathrm{RealSoftMax}(\lambda a, \lambda b) \sim b$.

    4. soft-min会是什么样子

        A: Soft-min 是 soft-max 的一个对偶定义，可以理解为类似的运算，但反映了“取较小值”的平滑版本。真实的 soft-min 定义如下：

        $\mathrm{RealSoftMin}(a, b) = -\log(\exp(-a) + \exp(-b))$


        解释：

        1. 软最大值 $(\mathrm{RealSoftMax}(a, b))$ 是对 $\max(a, b)$ 的平滑逼近。
        2. 软最小值 $(\mathrm{RealSoftMin}(a, b))$ 是对 $\min(a, b)$ 的平滑逼近。

        原理：
        1. Soft-max 使用了 $\log$ 和 $\exp$ 操作来将两数的较大值更突出（增加它的权重）。
        2. Soft-min 通过在 $\exp$ 内取负值，将较小值的权重突出。
        3. 两者的公式对称性可以归因于对数和指数的性质。

        例如：

        $\lim_{a \to -\infty} \mathrm{RealSoftMin}(a, b) = \min(a, b)$

        这种方法通常在需要平滑过渡且涉及最小值的优化问题中使用。

    5. 将其扩展到两个以上的数字。

    定义扩展到 n 个数字

    $
    \mathrm{RealSoftMax}(x_1, x_2, \dots, x_n) = \log \left( \sum_{i=1}^n \exp(x_i) \right)
    $
    
    通过对exp的和取对数，得到一个值，它是所有输入的“平滑最大值”的近似。

    在机器学习中通常提到的 Softmax 是一个归一化函数，它会输出一个概率分布。两者的区别在于：
    
    softmax输出每个值相对于其指数和的比值，$\mathrm{Softmax}(x_i) = \frac{\exp(x_i)}{\sum_{j=1}^n \exp(x_j)}$

    RealSoftMax: 只输出所有指数和的对数。

    RealSoftMax 常用于 log-sum-exp 操作中，用于避免数值上直接计算 max 时可能带来的不连续或梯度问题，尤其在优化问题中广泛应用。
