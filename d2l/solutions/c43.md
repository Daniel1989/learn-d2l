	1.	从简单的网络开始，比如1到2个隐藏层（3-5层，中等问题，更多的隐藏层就是对应很复杂的问题了）。
	2.	使用适中的学习率（比如 0.001 到 0.01）并尝试学习率调度。
	3.	在网络较深时加入 Dropout 或 L2 正则化以防过拟合。
	4.	通过交叉验证或验证集来评估不同配置的效果，逐步调整。

2. 尝试不同的激活函数，哪个效果最好？

在多层感知机（MLP）中，激活函数的选择确实对模型的表现有很大的影响。不同的激活函数在不同的任务和数据集上表现可能会有差异，但常见的激活函数中，以下几种比较常用且效果较好：

1.	ReLU (Rectified Linear Unit)
	+ 效果：通常效果很好，特别是在深度网络中。它的计算简单且能有效缓解梯度消失问题。
	+ 缺点：有可能会导致“死神经元”问题（即某些神经元永远不会激活）。
2.	Leaky ReLU
	+ 效果：它是ReLU的一种改进，通过在负值区域加入一个很小的斜率来避免死神经元问题。
	+ 缺点：虽然改进了死神经元问题，但仍可能存在梯度爆炸或梯度消失问题，尤其在网络很深时。
3.	ELU (Exponential Linear Unit)
	+ 效果：比ReLU更能有效处理负值区域，提供更平滑的输出，有助于加速收敛。
	+ 缺点：计算上比ReLU稍微复杂一些，但通常效果更好。
4.	Sigmoid
	+ 效果：较常见的激活函数，尤其在输出层用于二分类问题。
	+ 缺点：容易导致梯度消失问题，尤其是在深层网络中，导致训练困难。
5.	Tanh
	+ 效果：比Sigmoid稍好，范围是-1到1，避免了Sigmoid的饱和问题。
	+ 缺点：同样存在梯度消失问题。
6.	Swish
	+ 效果：Swish是由Google提出的，具有较好的性能，尤其在深度网络中表现优于ReLU。
	+ 优点：它是一个自定义的激活函数，结合了Sigmoid和ReLU的优势，具有连续和可微的性质，能够提供更好的梯度信息。

综上所述，ReLU和Leaky ReLU通常是最常用的选择，特别是对于大多数任务。如果网络较深或遇到梯度消失的问题，可以考虑ELU或Swish。不过，最终的效果还是依赖于任务和数据集，所以在实际应用中最好进行一些实验来验证不同激活函数的效果。
