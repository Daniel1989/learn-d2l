1. 假设我们有一些数据 $x_1, \ldots, x_n \in \mathbb{R}$, 我们的目标是找到一个常数b
，使得最小化$\sum_i (x_i - b)^2$
    
    1. 找到最优值b的解析解
        
        A: 最小化即找极值，所以就是求导数。对b求导

        a. $
f{\prime}(b) = \frac{d}{db} \sum_{i=1}^n (x_i - b)^2 = \sum_{i=1}^n 2(x_i - b)(-1) = -2 \sum_{i=1}^n (x_i - b)
$
        
        b. 令导数为0，则$
-2 \sum_{i=1}^n (x_i - b) = 0
$

        c. 所以答案为$
b = \frac{1}{n} \sum_{i=1}^n x_i
$，即所有数据的平均值


    2. 这个问题及其解与正态分布有什么关系?

        A: 当假设数据来自正态分布时，这个最小二乘估计过程等价于通过最大似然估计求解正态分布的均值参赛。因此，最小化平方误差的解时数据的样本均值，而在正态分布下，这也是正态分布的均值参数的最大似然估计


2. 推导出使用平方误差的线性回归优化问题的解析解。为了简化问题，可以忽略偏置
（我们可以通过向X添加所有值为1的一列来做到这一点）。

    1. 用矩阵和向量表示法写出优化问题（将所有数据视为单个矩阵，将所有目标值视为单个向量）。

        A. 解析解即为损失函数最小
$L(\mathbf{w}) = (\mathbf{X} \mathbf{w} - \mathbf{y})^T (\mathbf{X} \mathbf{w} - \mathbf{y})$

    2. 计算损失对w的梯度。

        A. 
        $
\nabla_{\mathbf{w}} L(\mathbf{w}) = 2 \mathbf{X}^T \mathbf{X} \mathbf{w} - 2 \mathbf{X}^T \mathbf{y}
$ 

        过程：分配律： $(a - b)^T (a - b) = a^T a - 2 a^T b + b^T b$  的矩阵版本。展开内积，得到$
L(\mathbf{w}) = (\mathbf{X} \mathbf{w})^T (\mathbf{X} \mathbf{w}) - 2 (\mathbf{X} \mathbf{w})^T\mathbf{y}  + \mathbf{y}^T \mathbf{y}
$ 结合律：
$(\mathbf{X} \mathbf{w})^T (\mathbf{X} \mathbf{w}) = \mathbf{w}^T \mathbf{X}^T \mathbf{X} \mathbf{w}$




        矩阵微分规则：
        1. 线性形式的导数

        如果函数是线性形式  $\mathbf{w}^T \mathbf{x}  或  \mathbf{x}^T \mathbf{w}$ ，其导数规则如下：

	    •	 $\frac{\partial (\mathbf{w}^T \mathbf{x})}{\partial \mathbf{w}} = \mathbf{x} $

	    •	 $\frac{\partial (\mathbf{x}^T \mathbf{w})}{\partial \mathbf{w}} = \mathbf{x} $

       其中， $\mathbf{w} \in \mathbb{R}^d ， \mathbf{x} \in \mathbb{R}^d $。


       2. 二次型形式的导数

          二次型是指形如  $\mathbf{w}^T \mathbf{A} \mathbf{w}$ 的表达式，其中  $\mathbf{A}$  是一个对称矩阵， $\mathbf{w}$  是一个列向量。

          •	 $\frac{\partial (\mathbf{w}^T \mathbf{A} \mathbf{w})}{\partial \mathbf{w}} = 2 \mathbf{A} \mathbf{w} $

          如果  $\mathbf{A}$  是对称的，这个导数就是  $2 \mathbf{A} \mathbf{w}$ 。如果  $\mathbf{A}$  不是对称的，则结果为  $(\mathbf{A} + \mathbf{A}^T) \mathbf{w}$ 。

        3. 常用的标量矩阵表达式的导数

	       •	对于标量  $\mathbf{w}^T \mathbf{x}$ ，其对向量  $\mathbf{w}$  的导数为：

              $\frac{\partial (\mathbf{w}^T \mathbf{x})}{\partial \mathbf{w}} = \mathbf{x}$

              这个规则类似于常见的标量导数。

	       •	对于二次型函数  $\mathbf{w}^T \mathbf{A} \mathbf{w}$ ：

              $\frac{\partial (\mathbf{w}^T \mathbf{A} \mathbf{w})}{\partial \mathbf{w}} = 2 \mathbf{A} \mathbf{w}$

             特别地，当  $\mathbf{A}$  是单位矩阵时，这个公式会退化为  $\frac{\partial (\mathbf{w}^T \mathbf{w})}{\partial \mathbf{w}} = 2 \mathbf{w}$ 。

   2. 计算损失对w的梯度。

        A: 令求导函数为0，且假设$ \mathbf{X}^T \mathbf{X} $可逆（不可逆则可能存在无数解或者无解），则 答案为 $
\mathbf{w} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}
$

   2. 计算损失对w的梯度。

        A: 在小规模数据集和简单模型中，使用解析解或其他优化方法通常优于随机梯度下降，尤其是当求解精度要求高时。然而，SGD在处理大规模数据、在线学习以及复杂模型时更为灵活有效，尽管它可能在特定情况下失效，如小样本、噪声数据、学习率不当等。因此，选择合适的优化方法需要考虑数据规模、模型复杂性、求解精度和具体任务等多个因素。


2. 假定控制附加噪声的噪声模型是指数分布。也就是说，$p(\epsilon) = \frac{1}{2} \exp(-|\epsilon|)$

   1. 写出模型$-\log P(\mathbf y \mid \mathbf X)$下数据的负对数似然。

        A. 假设我们有数据 (  $\mathbf X$ ) 和观测 ( $\mathbf y$ )，而模型假设 ( $\mathbf y = f(\mathbf X) + \epsilon $)，其中 ( f(\mathbf X) ) 是关于 ( \mathbf X ) 的模型预测，( \epsilon ) 是噪声，且噪声服从上述分布。

        1. 观测的条件概率

        条件概率 ( $P(\mathbf y \mid \mathbf X)$ ) 是在给定 ( $\mathbf X$ ) 的情况下，观测到 ( $\mathbf y$ ) 的概率。因为噪声 ( $\epsilon = y - f(\mathbf X)$ ) 服从指数分布，因此单个观测 ( $y_i$ ) 的条件概率为：

        $P(y_i \mid \mathbf X_i) = p(\epsilon_i) = \frac{1}{2} \exp(-|\epsilon_i|) = \frac{1}{2} \exp(-|y_i - f(\mathbf X_i)|)$


        2. 负对数似然

        负对数似然是整个数据集的联合概率取负对数。设  N  是样本数量，则数据的联合概率为：

        $P(\mathbf y \mid \mathbf X) = \prod_{i=1}^{N} P(y_i \mid \mathbf X_i) = \prod_{i=1}^{N} \frac{1}{2} \exp(-|y_i - f(\mathbf X_i)|)$


        取负对数：

        $-\log P(\mathbf y \mid \mathbf X) = -\log \left( \prod_{i=1}^{N} \frac{1}{2} \exp(-|y_i - f(\mathbf X_i)|) \right)$


        利用对数的性质  $\log(ab) = \log(a) + \log(b)$  和  $\log(\prod a_i) = \sum \log(a_i)$ ，得到：

        $-\log P(\mathbf y \mid \mathbf X) = -\sum_{i=1}^{N} \log\left( \frac{1}{2} \exp(-|y_i - f(\mathbf X_i)|) \right)$


        $= -\sum_{i=1}^{N} \left( \log\left(\frac{1}{2}\right) + \log\left( \exp(-|y_i - f(\mathbf X_i)|) \right) \right)$


        化简得到：

        $-\log P(\mathbf y \mid \mathbf X) = -\sum_{i=1}^{N} \left( -\log(2) - |y_i - f(\mathbf X_i)| \right)$


        $= N \log(2) + \sum_{i=1}^{N} |y_i - f(\mathbf X_i)|$


        因此，负对数似然函数为：

        $-\log P(\mathbf y \mid \mathbf X) = N \log(2) + \sum_{i=1}^{N} |y_i - f(\mathbf X_i)|$

        这个表达式包含了一个常数项  N \log(2)  和一个绝对误差的和。

   1. 试着写出解析解

        A: 这个问题实际上是最小绝对偏差$（LAD）$回归问题，也叫做L1回归。由于 ($L_1$) 范数包含绝对值运算，使得损失函数不可导。特别是，当 $( y_i = \mathbf w^\top \mathbf x_i )$ 时，残差的导数在这个点是不连续的。因此，像普通最小二乘法（OLS）那样，通过直接求导并解方程的解析解并不存在。

        LAD 回归的一般解析解需要使用线性规划或通过数值优化（例如迭代加权最小二乘法（IRLS））来得到。在这种情况下，直接求出解析解并不容易，因此通常会采用迭代方法来进行优化。

    1. 提出一种随机梯度下降算法来解决这个问题。哪里可能出错？（提示：当我们不断更新参数时，在驻点附近会发生什么情况）请尝试解决这个问题。

        A: 要使用随机梯度下降（SGD来解决LAD回归问题，我们需要针对 $( L_1 )$ 范数损失函数 $( L(\mathbf{w}) = \sum_{i=1}^n |y_i - \mathbf{w}^\top \mathbf{x}_i| )$ 进行求解。由于 $( L_1 ) $损失函数的非光滑性（特别是在残差等于零的地方），随机梯度下降在这个问题上可能会面临一些挑战。


        1. 损失函数的梯度

        对于 LAD 回归问题，损失函数 $( L(\mathbf{w}) )$ 对模型参数的梯度并不像 $( L_2 )$ 范数损失那样直接。因为 $( L_1 )$ 范数中的绝对值函数不可导，但它的次梯度可以用于求解。

        具体来说， $( L(\mathbf{w}) )$ 的次梯度如下：

	$•	当 ( y_i - \mathbf{w}^\top \mathbf{x}_i > 0 ) 时，梯度为 ( -\mathbf{x}_i )
	•	当 ( y_i - \mathbf{w}^\top \mathbf{x}_i < 0 ) 时，梯度为 ( \mathbf{x}_i )
	•	当 ( y_i - \mathbf{w}^\top \mathbf{x}_i = 0 ) 时，梯度不唯一，介于 ( -\mathbf{x}_i ) 和 ( \mathbf{x}_i ) 之间$

我们可以利用次梯度来更新模型参数。

2. 更新规则

随机梯度下降的更新规则是：

$\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} - \eta \cdot g_i(\mathbf{w}^{(t)})$

其中，$( g_i(\mathbf{w}) )$ 是在第 (i) 个样本上的次梯度，$( \eta )$ 是学习率。

3. 算法步骤

	1.	初始化参数 $( \mathbf{w} )$ （可以为零或随机初始化）。
	2.	对每个数据点 $( (x_i, y_i) )$，根据当前的残差 $( r_i = y_i - \mathbf{w}^\top \mathbf{x}_i )$ 计算次梯度：
	$•	若 ( r_i > 0 )，则 ( g_i(\mathbf{w}) = -\mathbf{x}_i )
	•	若 ( r_i < 0 )，则 ( g_i(\mathbf{w}) = \mathbf{x}_i )
	•	若 ( r_i = 0 )，则 ( g_i(\mathbf{w}) ) 介于 ( -\mathbf{x}_i ) 和 ( \mathbf{x}_i ) 之间$
	3.	更新参数：

$\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} - \eta \cdot g_i(\mathbf{w}^{(t)})$

4.	重复上述步骤直到收敛。

驻点附近的问题

在 LAD 回归中，驻点问题（即在某些 $( \mathbf{w} )$ 处的梯度非常接近零）会在残差为零的情况下出现。具体来说，当 $( y_i - \mathbf{w}^\top \mathbf{x}_i = 0 )$ 时，损失函数的梯度是不确定的，因为它处在 $( -\mathbf{x}_i )$ 和 $( \mathbf{x}_i )$ 之间的任意值。因此，在这个位置，模型更新可能会陷入停滞，无法继续优化。

解决驻点问题的方法

为了解决驻点问题，有几种可行的方法：

1. 添加平滑项
可以通过在损失函数中添加一个小的正则化项（如 ( L_2 ) 范数）来使得问题在驻点处平滑。这种做法称为Elastic Net，它结合了 ( L_1 ) 和 ( L_2 ) 范数，从而在模型处于驻点附近时能够提供一些光滑性。

Elastic Net 损失函数：

$L(\mathbf{w}) = \sum_{i=1}^n |y_i - \mathbf{w}^\top \mathbf{x}_i| + \frac{\lambda}{2} \|\mathbf{w}\|^2$

其中，$(\lambda)$ 是正则化强度的权重。

添加了 ( L_2 ) 项后，即使在驻点处，梯度仍然不为零，因此可以继续更新参数。

2. 使用加权最小二乘法的近似
另一种解决驻点问题的方法是使用加权最小二乘法，即通过将 ( L_1 ) 损失函数近似为加权 ( L_2 ) 损失，并通过迭代更新权重来优化模型。这种方法通常称为迭代加权最小二乘法（IRLS），在每次迭代中，模型对每个数据点的残差进行加权，使得 ( L_1 ) 损失逐步逼近最优解。

3. 在残差为零时随机选择梯度
在驻点处，损失函数的梯度不唯一，可以引入随机性来选择次梯度。在 $( y_i - \mathbf{w}^\top \mathbf{x}_i = 0 )$ 时，随机选择次梯度值 $( g_i(\mathbf{w}) ) 介于 ( -\mathbf{x}_i )$ 和 $( \mathbf{x}_i )$ 之间。这可以避免模型在驻点处完全停滞不前。

总结

随机梯度下降用于 LAD 回归时，驻点附近的梯度问题是主要的挑战。可以通过以下几种方式来解决：

	1.	添加 ( L_2 ) 正则化来平滑损失函数（Elastic Net）。
	2.	使用迭代加权最小二乘法（IRLS）来逐步逼近  L_1  损失。
	3.	在驻点处随机选择次梯度，避免更新停滞。

这些方法可以帮助避免在驻点处的梯度问题，从而让随机梯度下降更好地收敛到 LAD 回归的最优解。
