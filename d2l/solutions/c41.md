1. 计算pReLU激活函数的导数。

    A： pReLU 的导数可以表示为：

    $f{\prime}(x) =
    \begin{cases}
    1 & \text{if } x \geq 0 \\
    \alpha & \text{if } x < 0
    \end{cases}$


    因此，pReLU 的导数在 x $\geq$ 0 时为 1，在 x < 0 时为 $\alpha$，并且 $\alpha$ 是一个可学习的参数。

2. 证明一个仅使用ReLU（或pReLU）的多层感知机构造了一个连续的分段线性函数。

    A: 
    1. 无论是 ReLU 还是 pReLU，它们都是连续的分段线性函数。
    2. 每一层 MLP 的神经元应用一个线性变换 z = Wx + b，其中 W 是权重矩阵，b 是偏置向量。这些线性变换不会改变输入函数的分段线性性质，因为线性函数本质上是一个特殊的分段线性函数（只有一个线性片段）。
    3. 当输入通过 ReLU 激活时，会根据输入的不同区域（例如 $Wx + b > 0 或 Wx + b \leq 0$）分裂成不同的线性部分。例如：

        $y = \text{ReLU}(Wx + b)$

        对于每个神经元，它会根据 $Wx + b > 0 或 Wx + b \leq 0$ 将输入空间划分成两个区域。在每个区域，输出是一个线性函数。
    4. 将 ReLU 组合成多层感知机时，分段线性性会被递归扩展：

	    1. 第 k 层的输出是前 k-1 层输出的线性组合加偏置，然后通过 ReLU。

	    2. 因为每一层的 ReLU 激活进一步划分输入空间，这导致输出的分段数量随着网络深度和宽度的增加而指数增长。

	    3. 在每个分段内，网络的输出是一个线性函数。

        例如，两层 MLP 的表达为：

        $f(x) = W_2 \cdot \text{ReLU}(W_1 x + b_1) + b_2$

        这仍然是一个连续的分段线性函数。

    5. 连续性证明

        MLP 的连续性来自于：
        1.	线性变换 Wx + b 的连续性。
        2.	ReLU 本身的连续性。

        因此，整个网络的输出是连续的。

3. 证明$\operatorname{tanh}(x) + 1 = 2 \operatorname{sigmoid}(2x)$

    A: 
    
    1. tanh(x) = (e^x - e^-x) / (e^x + e^-x)
    2. sigmoid(x) = 1 / (1 + e^-x)
    3. tanh(x) + 1 = 2*e^x / (e^x + e^-x)
    4. 两边乘以 e^-x, 得到 2 / (1+e^-2x), 即 2 * sigmoid(2x)


4. 假设我们有一个非线性单元，将它一次应用于一个小批量的数据。这会导致什么样的问题？

    A:
    
    1. 归一化范围不正确

        •	问题：softmax 的输出是对输入向量按指数函数归一化的概率分布。如果将 softmax 一次应用于整个小批量数据（假设每一行是一个样本），则它会将小批量数据看成一个整体进行归一化，而不是对每个样本独立归一化。
        
        •	结果：这会导致输出的概率分布跨样本被混合，无法正确表示每个样本的独立概率分布。

    2. 梯度计算异常

    	•	问题：深度学习的损失函数（如交叉熵）通常依赖于 softmax 输出和真实标签之间的逐样本计算。如果 softmax 被误应用于整个小批量，则梯度的方向和大小可能会受到影响。

	    •	结果：模型的训练效果会变差，甚至无法正确优化目标函数。

    3. 数值稳定性问题

        •	问题：当小批量中某些样本的数值范围差异很大时，softmax 的指数运算会进一步放大这种差异，可能导致数值溢出或下溢。

	    •	结果：影响模型的训练稳定性，甚至导致 NaN 问题。

    4. 语义混淆
    	•	问题：softmax 的意义在于为单个输入向量生成概率分布。如果将小批量作为整体处理，这种语义会被破坏。

    	•	结果：模型的输出不再能直观地表示每个样本的分类概率。

    解决方案：确保 softmax 是对每个样本的向量独立应用，而不是对整个小批量的数据同时应用。
